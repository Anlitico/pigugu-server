设计说明(对照 PRD §5.6)

入口 A:在「我的」的设置分组新增一行「固件版本」,与现有列表结构一致,改动最小。

入口 B:页面右上角设置齿轮 → 下拉菜单「固件版本」。需新增齿轮(全局顶栏 or 我的页),按此比选。

「立即升级 / 预约升级」进入的是同一个全屏升级页(PRD §5.4)——与设备卡横幅共用一套状态机,行为不分叉。

检查更新 = 重新拉取该设备固件摘要(后端 GET /devices / GET /firmware 已有),短暂转圈。

多设备:每台一行,操作只作用于该行。

手机上点左上 ← 返回;场景/操作按钮在顶栏。设备行内 [检查更新] 也可单独点。
